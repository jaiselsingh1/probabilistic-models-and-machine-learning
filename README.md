## Box's loop: is the marathon wall a latent regime?

[`experiments/marathon_wall/`](experiments/marathon_wall/) is one turn of Box's
loop on the Boston Marathon 5K checkpoint grid, written up as Question 3 of
[homework 1](homeworks/hw1.tex). It asks whether late-race deceleration comes
from one continuous fatigue distribution or from two regimes, and it answers by
comparing a two-component mixture against a *unimodal skew-normal* control, so
the mixture cannot win on skewness alone.

```bash
uv run python -m experiments.marathon_wall.fetch_data --data-dir data/boston
uv run python -m experiments.marathon_wall.run_analysis \
    --data-dir data/boston \
    --out-dir experiments/marathon_wall/outputs \
    --fig-dir homeworks/figures --stage all
uv run python -m experiments.marathon_wall.make_tex_macros \
    --out-dir experiments/marathon_wall/outputs \
    --tex homeworks/figures/wall_numbers.tex
```

Every number in the write-up is a LaTeX macro generated by that last command, so
the prose cannot drift away from the fit. The race files are third-party and are
not committed; `fetch_data` downloads 2013--2014 and explains where to put the
2015--2017 files, which the loader picks up automatically if present.
