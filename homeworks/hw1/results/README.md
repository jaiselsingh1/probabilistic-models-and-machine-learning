# Audited HW1 results

Generated by `python -m homeworks.hw1.audited_analysis` from pinned public CSV files. This directory supplies the revised Q3. The repository's `experiments/marathon_wall/outputs/` directory contains historical Bayesian experiments and does not supply the revised submission.

- `verification.json`: independent recomputation of the original split, training references, pointwise scores, table entries, component crossovers, bulk/tail gains, and generated LaTeX macros, plus a derivative-based mode cross-check. Run `python -m homeworks.hw1.verify_results` after generating the detailed CSVs.
- `results.json`: input hashes, versions, cohort accounting, split seed, all fitted parameters and optimization diagnostics.
- `comparisons.csv`: paired held-out log-score gains and conditional standard errors. Within the original variants (`q25`, `raw`, `q10`, `q50`), rows marked `2014 only` score that subset using the original preprocessing. The new `q25_2014` variant refits both the reference and models using only original 2014 training records, preserving their original held-out records.
- `cohort.csv`: eligible record identifiers, raw response, baseline pace, and train/test partition.
- `heldout_scores.csv`: pointwise log densities, predictive CDFs, and component responsibilities for independent recomputation of summaries.
- `reference_*.csv`: training-only reference curves.
- `reference_q25_2014.csv`: the separate 2014-only training reference.
- `mixture_diagnostics.csv`: primary group SD ratios, squared variance ratios, and the two weighted-component equality roots. The higher-mean component has fitted responsibility above 50% below the left root and above the right root.
- `score_gain_partition.csv`: counts, signed log-score gains, and percentages of the total primary net gain. Each group's training response 5th and 95th percentiles fix the lower tail, inclusive central interval, and upper tail. The three contributions are exhaustive; a negative share is retained.
- `training_year_composition.csv`: training counts and raw-response summaries by year in fixed baseline-pace bins near the plotted kink. These are descriptive and do not identify a causal interruption effect.
- `diagnostics.json`: definitions and full-precision copies of the component, gain-partition, and composition tables. A centered response below zero does not by itself imply actual speeding up.
- `hygiene.csv`: loader exclusions; also see the final endpoint-completeness exclusion in `results.json`.

The score errors condition on trained fits and fixed stratum counts, assume independent records within strata, and omit training-set, model-selection, and between-race uncertainty. Records can be repeat performances by the same athlete across years. The original project had already explored these data; this is an internal refit diagnostic, not independent confirmation. The raw and alternative-quantile rows share the same holdout.
