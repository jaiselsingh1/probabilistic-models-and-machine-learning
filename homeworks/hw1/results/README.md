# Audited HW1 results

Generated by `python -m homeworks.hw1.audited_analysis` from pinned public CSV files. This directory supplies the revised Q3. The repository's `experiments/marathon_wall/outputs/` directory contains historical Bayesian experiments and does not supply the revised submission.

- `verification.json`: independent recomputation of all pointwise scores and table entries, plus a derivative-based mode cross-check. Run `python -m homeworks.hw1.verify_results` after generating the detailed CSVs.
- `results.json`: input hashes, versions, cohort accounting, split seed, all fitted parameters and optimization diagnostics.
- `comparisons.csv`: paired held-out log-score gains and conditional standard errors for the primary specification, uncentered outcome, and two centering sensitivities. Rows marked `2014 only` score that held-out subset using the shared reference learned from both years; they are not a 2014-only preprocessing refit.
- `cohort.csv`: eligible record identifiers, raw response, baseline pace, and train/test partition.
- `heldout_scores.csv`: pointwise log densities, predictive CDFs, and component responsibilities for independent recomputation of summaries.
- `reference_*.csv`: training-only reference curves.
- `hygiene.csv`: loader exclusions; also see the final endpoint-completeness exclusion in `results.json`.

The score errors condition on trained fits and fixed stratum counts, assume independent records within strata, and omit training-set, model-selection, and between-race uncertainty. Records can be repeat performances by the same athlete across years. The original project had already explored these data; this is an internal refit diagnostic, not independent confirmation. The raw and alternative-quantile rows share the same holdout.
